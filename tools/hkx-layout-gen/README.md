# hkx-layout-gen

Makes the bundled HKX2Library able to read and write **32-bit (Skyrim LE)**
packfiles as well as 64-bit (Skyrim SE) ones.

## Why this exists

`libs/HKX2Library/HKX2/Autogen/` was generated by dumping Havok classes from
the **Skyrim SE runtime**, so every generated `Read`/`Write` body has its
alignment padding baked to an 8-byte pointer:

```csharp
m_flags = br.ReadSByte();
br.Position += 4;              // pad to align the next hkArray to 8
des.ReadEmptyArray(br);
```

Skyrim LE uses the *same Havok schema* (`hk_2010.2.0-r1`, class version 8) but
a 4-byte pointer, so those constants are wrong there — that padding should be
0. The pointer and array primitives were already pointer-size aware; only the
per-class padding was not.

## What it does

`relayout.py` reconstructs Havok's layout rules from the metadata comments each
generated class already carries (member type, `arrSize`, flags, 64-bit offset,
class size), then rewrites the padding to carry both values:

```csharp
br.Position += des.Padding(4, 0);   // 4 bytes at 64-bit, 0 at 32-bit
```

It also inserts padding where only the 32-bit layout needs it, rewrites
`hkUlong` members to the pointer-sized `ReadUSize`/`WriteUSize`, and accounts
for the extra vtable pointers that multiply-inherited classes carry.

## The safety property

The script **simulates each body and requires the model to reproduce the
64-bit constant already in the source**. If it can't, the class is reported as
a failure and left untouched rather than guessed at. So Skyrim SE output cannot
change: every emitted `pad64` is exactly what was there before.

Classes it can't model are written to `libs/HKX2Library/HKX2/PointerSizeSupport.cs`,
which the editor consults to refuse an LE save rather than write a corrupt file.

## Usage

```bash
python relayout.py --check   # validate only, report what would change
python relayout.py           # rewrite Autogen/ in place
```

The rewrite is not idempotent — it consumes literal `Position += N` constants.
Re-run it from a clean tree:

```bash
git checkout -- libs/HKX2Library/HKX2/Autogen && python relayout.py
```

## Verifying

`tools/hkx-roundtrip` is the regression harness:

```bash
# SE must be unchanged: capture before, diff after
dotnet run --project tools/hkx-roundtrip -- <se-files...>

# LE corpus, converting both directions
dotnet run --project tools/hkx-roundtrip -- --convert <le-files...>
```

Last run: all 180 loose vanilla Skyrim LE files parse and convert to SE and
back with byte-identical Havok XML; SE samples byte-identical to baseline.
